# ТЗ: замена примера PDF для кнопки «Посмотреть пример PDF»

> Changelog
> - v1 (08.10.2026) — новый пример со скрытой памяткой; кэш file_id привязан к содержимому файла

## Контекст

По кнопке «Посмотреть пример PDF» бот отправляет `assets/example/Drema_plan_sna_primer.pdf` и сохраняет `file_id`, чтобы дальше отправлять по нему. Пример заменён: в новой версии страницы памятки растрированы и размыты (памятка платная, бесплатно её показывать не хотим). Сейчас бот может продолжать отправлять старый файл по сохранённому `file_id`.

Перед изменениями коротко опиши план и список файлов. Жди подтверждения.

## Приложенные файлы

| Файл | Куда |
|---|---|
| `Drema_plan_sna_primer.pdf` | заменить `assets/example/Drema_plan_sna_primer.pdf` |
| `blur_example.py` | `templates/pdf/blur_example.py` (скрипт, которым сделан пример; в боте не используется) |

## Что сделать

1. **Замени файл** `assets/example/Drema_plan_sna_primer.pdf` на приложенный. Имя и путь не меняй.

2. **Сбрось сохранённый `file_id` примера.** Найди, где он хранится (БД, кэш процесса, переменная), и покажи мне это место. Удали сохранённое значение, чтобы при следующем нажатии файл загрузился заново.

3. **Сделай так, чтобы это не повторялось при следующих заменах.** Привязывай сохранённый `file_id` к содержимому файла: при старте считай хэш (например, SHA-256) файла примера и храни `file_id` вместе с этим хэшем. Если хэш файла не совпадает с сохранённым, считай `file_id` недействительным и загружай файл заново. Если `file_id` хранится только в памяти процесса, достаточно убедиться, что после деплоя он не переживает перезапуск, и сказать мне об этом.

4. **Если отправка по `file_id` падает** (Telegram вернул ошибку), загружай файл заново и сохраняй новый `file_id`, а не показывай ошибку пользователю.

5. **Добавь в README** (раздел про контент или ассеты) короткую заметку: «Пример PDF для кнопки — `assets/example/Drema_plan_sna_primer.pdf`. Страницы памятки в нём размыты скриптом `templates/pdf/blur_example.py`: `python3 templates/pdf/blur_example.py <исходный.pdf> assets/example/Drema_plan_sna_primer.pdf`. После замены файла `file_id` обновится автоматически».

Тексты сообщений (`texts.exampleFollowup` и др.) не трогай.

## Проверка

- [ ] После деплоя нажать «Посмотреть пример PDF»: приходит новый файл, страницы памятки (5 и 6) размыты, поверх первой плашка «Полная памятка — в вашем плане».
- [ ] Повторное нажатие отправляет файл по `file_id` (в логах видно, что повторной загрузки не было).
- [ ] Локально заменить файл на любой другой PDF и перезапустить: бот загружает файл заново, а не отправляет старый `file_id`. После проверки вернуть правильный файл.
